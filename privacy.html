1. About this policy

This Privacy Policy explains what information the NEXUS Discord application ("NEXUS", "the bot") processes when you use it in the NEXORA Discord community, why, how long it is kept, who it is shared with, and the choices you have. NEXUS is developed and operated by SHADOW ("we", "us").

This policy was written by reviewing the NEXUS source code and database schema (version installed as of 19 November 2026). It describes what the software actually does. Where a fact depends on how the operator runs the bot (for example where it is hosted, or how deletion requests are handled) it is marked CONFIRM and must be completed by the developer before publication.

This policy covers only NEXUS. Discord itself collects and processes your data under the Discord Privacy Policy, which is separate from this one.

Message content

NEXUS uses Discord's message-content access. Message text is read in memory to decide whether a message earns XP (minimum length, cooldown, repeat detection) and, if the AI assistant is enabled, to detect when NEXUS or the server owner is mentioned. Message text is not stored in the database, except: the 200-character mention excerpt described above, text you deliberately submit (bio, assistance details, report reasons, game profile fields), and text staff enter (moderation reasons, review notes, protocols). The NEXUS monitoring system (NSIS) is built to reject message content: only a fixed list of operational event types is accepted.

Log files, backups and temporary queues

  • Log files (nexus.log, errors.log) record operational activity and errors. They can contain Discord user IDs, command names, error details and, for example, a Minecraft username if a lookup fails. Tokens and passwords are redacted automatically.
  • Database backups are full copies of the database, created only when the Architect runs /staff backup.
  • Dead-letter files temporarily hold monitoring and security events if the database is unavailable, until they can be written to the database.

What NEXUS does not collect

  • No voice audio, no screen content, no files you upload to Discord.
  • No email addresses, phone numbers, real names, passwords, IP addresses or payment information (Discord does not give these to bots).
  • No advertising identifiers, tracking pixels or cookies. This website is static and contains no analytics or cookies.

4. How the information is used

  • Community features: profiles, rank cards, leaderboards, automatic rank roles, gaming profiles and leaderboards, looking-for-team posts, clips and polls.
  • Progression: calculating text and voice XP and levels, and preventing XP farming (cooldowns, minimum message length, repeated-message detection, voice rules such as requiring at least two people in a channel).
  • Safety and moderation: recording moderation actions, handling member reports and assistance requests, and keeping an audit trail.
  • Security: verifying permissions for every command, recording restricted-command use and denied attempts, and notifying the server owner (Architect) by direct message.
  • Reliability: NSIS monitors the bot's health, detects unusual activity and reports problems to staff.
  • Notifications: optional direct messages (for example level-ups), which you can switch off with /notifications.
  • AI assistant (if enabled): generating replies to members who mention NEXUS or the server owner.

NEXUS has no feature that sells your information or uses it for advertising.

6. Third-party services

Discord

NEXUS runs on Discord. All information NEXUS receives comes from Discord, and everything NEXUS sends is delivered through Discord. Discord's processing is governed by the Discord Privacy Policy and Terms of Service.

Google Gemini (AI assistant, optional)

The AI assistant is off by default and is only active if the operator enables it. When it is active and you mention NEXUS, post in a designated AI chat channel, reply to an AI message, or mention the server owner while they are away, NEXUS sends the following to Google's Gemini API to generate a reply: your message text (up to 1,500 characters), your server display name, the channel name, and the recent turns of that conversation. Your Discord user ID is not sent. AI replies are labelled in Discord.

Google processes this content under its own terms. Under Google's Gemini API terms, content sent through unpaid (free) quota may be used by Google to improve its products and may be reviewed by humans; content sent through paid quota is not used to improve Google's products. See the Gemini API Additional Terms and the Google Privacy Policy. Do not share personal or sensitive information with the AI assistant.

CONFIRMDeveloper: (1) state whether the assistant is enabled; (2) state whether you use free or paid Gemini quota, as this changes how Google may use members' messages; (3) Google's Gemini API terms have prohibited use in services directed at or likely to be accessed by people under 18. Check the current terms. If NEXORA admits members under 18, disable the assistant or restrict it before publishing.

Mojang / Microsoft (Minecraft username check, optional)

If the operator enables Minecraft username verification (off by default), the Minecraft Java username you register is sent to Mojang's public profile API (api.mojang.com) to confirm it exists. No other information is sent.

Hosting

NEXUS stores its database (SQLite or PostgreSQL) and log files on the machine or server where the operator runs it.

8. Your choices and deletion requests

What you can do yourself

  • /privacy: make your profile public or private.
  • /notifications: turn level-up, gaming and assistance direct messages on or off.
  • Edit or clear your bio from your profile panel (/nexus → Profile → Edit bio).
  • /bgmi unregister, /valorant unregister, /minecraft unregister (type DELETE to confirm): permanently deletes that game profile and its statistics.
  • Avoid mentioning NEXUS or the server owner if you do not want your message processed by the AI assistant.

Requests to the developer

To ask for a copy of your data, a correction, or deletion of data you cannot remove yourself (for example XP, history, or your profile record), contact [SUPPORT EMAIL — sameerpatelpvt.97@gmail.com] from the Discord account concerned, or include your Discord user ID so the request can be verified.

Some records, such as moderation and security records, may be kept where they are needed to protect the community; if a request is refused, you will be told why. Data deleted from the live database may remain in existing backup files until those backups are removed.

9. Security practices

The following safeguards are implemented in the NEXUS code:

  • Every command and button checks permissions in code, using numeric Discord role and user IDs, never names.
  • The most sensitive commands require both the Architect role and the Architect's verified user ID.
  • Restricted-command use and denied attempts are recorded in an append-only audit log and reported to the server owner.
  • Credentials (bot token, database password, API keys) are kept in a local configuration file that is excluded from version control, and are automatically redacted from logs and error messages.
  • Database queries use parameterized statements, and command inputs are validated and length-limited.
  • Rate limits and cooldowns apply to sensitive and costly actions.
  • The AI assistant cannot ping @everyone, @here, roles or users, and its replies are labelled as AI-generated.

No system is perfectly secure. The database file and backups are not encrypted by NEXUS itself; their protection depends on the security of the machine or server where NEXUS runs. NEXUS has not been independently audited or certified.
